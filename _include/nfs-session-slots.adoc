NFS 세션 슬롯은 NFSv3 슬롯 테이블에 해당하는 NFSv4.X 버전입니다. 기본값은 일반적으로 64입니다. ONTAP의 세션 제한과 일치하므로 180이 최적의 값입니다.

max_session_slots 매개변수 설정 예시:

....
# cat /etc/modprobe.d/nfsclient.conf
 options nfs max_session_slots=180
....
이 매개변수는 시작 시 로드되는 커널 모듈에서 사용됩니다. NFSv3 슬롯 테이블 매개변수와 달리 동적이지 않습니다. 이 변경 사항을 적용하려면 재부팅해야 합니다.


CAUTION: 이 매개변수를 설정하지 않으면 성능에 상당한 영향을 미칠 수 있습니다. linux OS가 충분한 I/O를 발생시키지 않아 성능이 크게 제한될 수 있습니다.
